## 🏗️ Proyectos Destacados

* **Prometheus:** Es el proyecto insignia en el que he trabajado como Desarrollador Full-Stack, creado para satisfacer las altas exigencias operativas y de seguridad del sector salud. A nivel de Backend, diseñé una API en .NET 8 utilizando Dapper para exprimir al máximo el rendimiento de PostgreSQL. Uno de mis mayores logros en este sistema fue la implementación de Background Workers autónomos que monitorean la base de datos de forma asíncrona para despachar alertas de resultados médicos críticos, garantizando que el personal de salud reaccione a tiempo sin saturar el servidor principal. En el Frontend, construí una Single Page Application (SPA) con Angular y Tailwind CSS, enfocada en la experiencia del usuario (UX). Implementé desde Dashboards analíticos y gestores de inventario, hasta un sistema completo de digiturnos. Además, logré integrar el ecosistema web directamente con el hardware de los laboratorios, permitiendo la impresión silenciosa en equipos Zebra y POS, y diseñé una matriz de permisos dinámicos blindada con JWT.
* **CerberusHealth:** Arquitectura y desarrollo de un sistema integral de administración clínica veterinaria. Ecosistema construido con Angular, Node.js, Tailwind, C# .NET Core Web API y diseño de base de datos en PostgreSQL.
* **HealthBridge:** Diseño de la arquitectura técnica de una plataforma de integración multiplataforma (Windows Service autónomo) para centralizar conexiones de equipos de laboratorio mediante listeners multiprotocolo.
* **Sistemas de Gestión de Inventario:** Desarrollo de bases de datos y aplicativos de escritorio en VB.NET y PostgreSQL para el control de almacenes, productos y configuración de movimientos.
* **Gestión de Órdenes de Laboratorio:** Construcción de interfaces web para la administración de órdenes clínicas con autenticación mediante tokens API y serialización de peticiones.
* **Mecanismos de Auditoría y Logging:** Implementación de sistemas de trazabilidad con escritura síncrona en disco local para auditar procesos operativos críticos dentro del código fuente.
